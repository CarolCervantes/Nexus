### Uso de SQLite + Markdown en NEXUS (Fecha: 2026-11-13 01:39:17)
- **Contexto**: Necesidad de persistencia local confiable sin dependencias de red.
- **Decisión tomada**: Base de datos relacional SQLite como fuente de verdad y sincronizacion automatica a Markdown.
- **Justificación**: Proporciona ACID, atomicidad en Windows y legibilidad instantanea.
- **Impacto previsto**: Continuidad garantizada entre sesiones.
